# Pasos finales de publicación

La aplicación y el informe están terminados, pero tres enlaces deben generarse desde las cuentas personales del estudiante antes de entregar:

1. **GitHub**: crear un repositorio y subir todos los archivos de esta carpeta (excepto `demo-estatico` si se desea mantener el repositorio únicamente con Angular).
2. **Despliegue**: importar el repositorio en Netlify o Vercel. El proyecto incluye `netlify.toml` y `vercel.json`.
3. **Video**: grabar una explicación de máximo 3 minutos usando el guion incluido en el informe y subirla a YouTube.
4. Reemplazar en el Word/PDF las tres líneas que dicen `[PEGAR AQUÍ...]` por las URLs reales.

## Comandos locales
```bash
npm install
npm start
```

Para compilar:
```bash
npm run build
```
